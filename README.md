# CDP Platform — Restaurant Guest Marketing Portfolio

Live marketing website for CDP Platform — the Customer Data Platform for restaurant chains.

## Live Site
https://masimriaz.github.io/cdp-portfolio/

## About
CDP Platform turns restaurant guest data into automated marketing campaigns.
This portfolio site demonstrates CDP's business value, features, ROI model, and 90-day pilot offer.

## Tech
- Bootstrap 5.3.3
- Font Awesome 6.4
- Vanilla JS
- Zero build step — pure static HTML/CSS/JS
- GitHub Pages compatible

## Setup
1. Fork or clone this repo
2. Enable GitHub Pages: Settings → Pages → Deploy from branch: main / root
3. Site live at: https://<username>.github.io/cdp-portfolio/
